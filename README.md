# open-forms

## Objetivo

Sistema de formulários (CRUD) semelhante à soluções comerciais conhecidas como o Google Forms

## Especificações

1. O sistema deve ter uma interface de login e senha;
2. O sistema deve ter uma interface de listagem dos formulários;
   1. Cada item de formulário deve ser uma opção de visualização (link público), edição e/ou deleção
3. A interface de listagem deve ter uma opção de criação de um novo formulário;
4. A interface de criação de formulários deve ter opções para criação de "n" questões (mínimo duas)
